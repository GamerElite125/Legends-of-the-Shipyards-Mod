CSP Shipyard System for Caribbean Legend
Version 1.3.0

This build preserves the CSP custom ship commission and appearance systems
and restores the separate CSP ship-upgrade/refit workflow for Caribbean
Legend 1.1.1 and later.

Shipyard services:
- Standard Caribbean Legend sale and repair screen
- CSP custom-built ship commission screen
- CSP ship upgrade and refit screen
- Caribbean Legend ship appearance customization

The refit system includes:
- Merchant, universal, and warship upgrade templates
- Fourteen CSP refits with ship-type restrictions
- Three normal upgrade slots; additional slots for ordered, blueprint, and
  quest ships where supported
- Deposit pricing based on the selected real ship
- Class-scaled material requirements
- Persistent material delivery to the shipyard which accepted the order
- Construction-time advancement and persistent per-ship stat changes

The Flying Dutchman and Cursed Flying Dutchman, including Kraken,
submerge/emerge commands, models, dedicated textures, sounds, particles,
and commissioning registrations, have been removed at the user's request.
An old-save cleanup migration disables retained Dutchman definitions and
detaches owned Dutchman instances before their removed models can load.

Black Pearl, Cursed Black Pearl, Queen Anne's Revenge, Cursed Pearl fog,
and the Cursed Pearl sweep command remain part of the mod.

Install as a Steam Workshop content root. Do not copy the files into the
base game PROGRAM directory.
