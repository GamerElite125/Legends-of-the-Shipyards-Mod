CSP SHIPYARD PARITY REPORT 1.3.0

RESTORED
- CSP ship-upgrade interface separated from the stock CL shipyard interface
- Merchant, universal, and warship refit presets
- CSP upgrade-slot limits
- Ship-type eligibility
- Upgrade deposit
- Class-scaled cargo materials
- Shipyard ownership of an open refit order
- Partial material deliveries
- Completion time
- Persistent per-real-ship upgrade flags and compatible stat changes

CARIBBEAN LEGEND ADAPTATIONS
- Uses CL's native GOODS icon atlas because the CSP upgrade atlas is not part
  of the current resource archive.
- Runs as interface 51 with INTERFACE_QUANTITY increased to 52.
- Uses CL-compatible .tga interface paths.
- Applies only geometry-safe stat changes; it does not invent cannon locators
  or alter a hull model's physical gun-port count.

- Submerge/emerge command and state machine
- Dutchman models, portraits, sails, sounds, particles, and command art

PRESERVED

- Black Pearl

- Queen Anne's Revenge
- Cursed Pearl fog and sweep command

VALIDATION LIMIT
